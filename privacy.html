Política de privacidad

Última actualización: 14 de noviembre de 2026.

Esta política describe cómo Rupelive Studio accede, usa y almacena los datos de las cuentas de Google que autorizan su uso.

1. Responsable

Rupelive Studio es una aplicación Android de uso personal desarrollada por el titular de la cuenta de contacto sompaternacf@gmail.com.

2. Datos a los que accede

  • Identificador de la cuenta de Google que autoriza el acceso.
  • Información del canal de YouTube: identificador, nombre y emisiones planificadas.
  • Datos técnicos de las emisiones: estado, transmisión vinculada, dirección de ingesta RTMP y clave de emisión.
  • Tokens OAuth de acceso y actualización necesarios para mantener la sesión.

La aplicación no accede a los vídeos, mensajes, contactos ni a otros datos ajenos a la gestión de emisiones de YouTube.

3. Para qué se usan

  • Iniciar sesión en la cuenta de Google autorizada.
  • Listar las emisiones planificadas del canal y permitir seleccionar una.
  • Obtener la dirección y clave de ingesta para configurar el directo.
  • Iniciar y finalizar la emisión seleccionada mediante la API de YouTube.

Los datos se usan únicamente para prestar estas funciones. No se usan para publicidad, elaboración de perfiles ni fines ajenos.

4. Almacenamiento y seguridad

Los tokens y la configuración se almacenan localmente en el espacio privado de la aplicación en el dispositivo. La aplicación no dispone de un servidor propio ni envía los tokens a terceros. El vídeo y el audio se envían directamente al servicio RTMP de YouTube.

5. Compartición

No se venden, alquilan ni comparten datos personales con terceros. Solo se intercambia con Google la información necesaria para autenticar la cuenta y gestionar la emisión, conforme a las condiciones de las APIs de Google.

6. Conservación y eliminación

Los datos permanecen en el dispositivo hasta que el usuario cierra sesión, revoca el acceso de la aplicación o la desinstala. Para revocar el acceso desde Google:

https://myaccount.google.com/permissions

Al revocar el acceso o desinstalar la aplicación se eliminan los tokens almacenados localmente.

7. Uso limitado

El uso de la información recibida de las APIs de Google se limita a las funciones descritas en esta política y cumple la Política de datos de usuario de los servicios de las APIs de Google, incluidos los requisitos de Uso limitado.

8. Cambios

Cualquier cambio en esta política se publicará en esta misma página con una nueva fecha de actualización.

9. Contacto

Para consultas sobre privacidad o para solicitar la eliminación de datos: sompaternacf@gmail.com.
