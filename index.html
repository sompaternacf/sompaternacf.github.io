Rupelive Studio

Rupelive Studio es una herramienta privada para Android que permite preparar, componer y emitir directos en YouTube.

Qué hace la aplicación

  • Compone cámara, texto, imágenes, vídeo, web y playlists en una escena.
  • Conecta la escena a un destino RTMP de YouTube.
  • Con el permiso del usuario, consulta las emisiones planificadas de su canal y obtiene los datos necesarios para emitir.
  • Puede iniciar y finalizar una emisión planificada mediante la API de YouTube.

Privacidad

La aplicación no vende datos ni los comparte con terceros. Los tokens de acceso se guardan en el almacenamiento privado del dispositivo y el vídeo se envía directamente a YouTube.
